# TubeAI 공개 페이지 벤치마킹 정리 (2026-11-05)

tubeai.org 의 **공개 소개 페이지**(welcome.php 와 제작 종류별 소개 11개)만 읽었습니다. 로그인 뒤 화면은 보지 않았습니다(구글 로그인 전용).
구조와 작업 흐름만 참고했고, 디자인·문구·이미지·코드는 가져오지 않았습니다.

## 그쪽 구조

- 상단 메뉴: 제작 종류 · 편집기 · 멀티 게시 · AI 매니저 · Master(평생 이용권) · FAQ
- 제작 종류 13가지 카드: 나레이션 스튜디오(쇼츠~1시간 롱폼), 쇼핑쇼츠 리믹스/AI생성, AI 영상 편집기(참고 영상 재구성), 롱폼→쇼츠, 중드 쇼츠, 쇼츠 자동생성 10종(연예인·영화·일러스트·정책지원금·클립·정치·스포츠·번역·랭킹·운세), 연예인 쇼츠, 운세 쇼츠, 무비 스튜디오, 캐릭터&클립, 인스타 카드뉴스, 라이브 방송
- 제작 흐름 5단계: 소재 고르기 → AI 제작 → 필요하면 다듬기 → 서버에서 완성(창 닫아도 계속) → 올리고 운영
- 단계마다 멈춰 확인·수정 가능, 프로젝트 저장 후 다시 열기·다시 렌더링
- 편집기: 문장을 고치면 컷이 바뀌는 텍스트 기반 편집, AI 지우기·배경 제거·키프레임·색 보정·음성 나올 때 음악 줄이기
- 게시: 유튜브 업로드·예약 + 인스타·틱톡·페이스북·X·Threads (크롬 확장으로 게시, 비밀번호 저장 안 함)
- AI 매니저: 채널·쿠팡파트너스 실적 분석, 다음 영상 주제 추천
- 요금: 평생 이용권 + 크레딧(외부 AI 엔진 사용료)

## TubeForge 에 반영한 것

| 그쪽 | TubeForge |
|---|---|
| 제작 종류 카드 | 홈의 「제작 종류」: 나레이션 쇼츠 · 롱폼 · 기사 기반 쇼츠 (나머지는 「준비 중」으로 표시) |
| 5단계 흐름, 단계마다 멈춤 | ① 소재 → ② 대본 다듬기 → ③ 목소리·스타일 → ④ 렌더링 → ⑤ 결과·업로드 |
| 서버에서 완성 | 렌더링은 작업 큐에서 진행, 화면을 옮겨도 계속 + 왼쪽 아래 진행 표시 |
| 프로젝트 저장·재렌더링 | 「내 프로젝트」 카드, 대본 고쳐서 다시 만들기 |
| 여러 TTS 엔진 | edge(무료) · ElevenLabs, 목소리 미리듣기 |
| 음성 나올 때 음악 줄이기 | BGM 오디오 덕킹 |
| 유튜브 업로드·예약 | 결과 화면에서 업로드·예약 발행 |
