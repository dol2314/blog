# 모두바로(modubaro.com) 디자인 변신

GeneratePress 테마는 그대로 두고 **추가 CSS + 홈 페이지 1개**로 바꿉니다. 전부 되돌릴 수 있습니다.

## 1. 전체 디자인 (5분)
1. 워드프레스 관리자 → **외모 → 사용자 정의하기 → 추가 CSS**
2. `custom.css` 내용을 **통째로** 붙여넣고 → **발행**
3. Breeze 캐시 비우기: 관리자 상단 **Breeze → Purge All Cache**

되돌리기: 추가 CSS 를 비우고 발행.

## 2. 메뉴 정리 (2분, 권장)
메뉴가 길어 PC에서 답답해 보입니다. **외모 → 메뉴**에서
- 주 메뉴: `버리는 법 · 수수료와 신고 · 지역별 기준 · 소개` 만 남기고
- `개인정보처리방침 · 이용약관 · 연락처`는 빼서 **바닥글**로 옮깁니다
  (외모 → 위젯 → 바닥글 위젯에 '내비게이션 메뉴' 블록 추가, 또는 바닥글 메뉴 위치가 있으면 거기 지정).
애드센스 승인에 필요한 필수 페이지 링크는 바닥글에 남아 있으면 됩니다.

## 3. 첫 화면 (10분)
1. **페이지 → 새로 추가**, 제목 `홈`
2. 오른쪽 위 ⋮ → **코드 편집기**로 바꾸고 `home-page.html` 내용을 붙여넣기 → 다시 비주얼 편집기로
   (맨 아래 '최신 글' 블록이 자동으로 최근 글 9개를 카드로 보여 줍니다)
3. **공개** (Rank Math 제목: `모두바로 - 필요한 절차와 방법을 한 번에 정리합니다` 처럼 사이트 설명 유지)
4. **설정 → 읽기 → 홈페이지 표시: 정적인 페이지** → 홈페이지 `홈`, 글 페이지는 비워 둬도 됩니다
5. 캐시 비우기

되돌리기: 설정 → 읽기 → '최신 글'로 바꾸면 원래 첫 화면으로 돌아갑니다.

> 히어로의 '많이 찾는 품목' 버튼은 지금 있는 글 주소로 연결돼 있습니다. 바꾸려면 `<div class="mb-chips">` 안의 주소와 글자를 고치세요.
