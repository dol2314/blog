# 2026 프로야구 일정 중계 — Cloudflare Pages 배포 가이드

이 폴더를 그대로 Cloudflare Pages 에 올리면 됩니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 첫 화면: 다음 경기, 남은 일정, 채널 안내 |
| `day.html` | 날짜별 중계 안내 (`day.html#2026-11-01`) |
| `guide-tv.html`, `guide-tving.html` | TV 채널 안내, 모바일(티빙) 시청법 |
| `style.css`, `common.js`, `favicon.svg`, `_headers` | 디자인, 화면 동작, 아이콘, 캐시 설정 |
| `schedule.json` | 기본 일정 (10/31 기준 2026 시즌 전체 939경기) |
| `functions/api/schedule.js` | **일정 자동 갱신**: KBO 공식 일정에서 이번 달·다음 달을 받아 30분 보관 |
| `배포.bat` | 윈도우에서 두 번 클릭으로 배포 |

## 방법 1 — `배포.bat` 두 번 클릭 (추천, 자동 갱신 포함)

1. https://nodejs.org 에서 **LTS** 설치 (한 번만)
2. Cloudflare 계정 준비 (무료)
3. 이 폴더의 **`배포.bat`** 두 번 클릭
   - 브라우저가 열리면 Cloudflare 로그인 → **Allow(허용)**
   - 처음이면 프로젝트 `kbo2026` 이 자동으로 만들어집니다
4. 끝나면 나오는 `https://kbo2026.pages.dev` 같은 주소가 사이트입니다

수정 후 다시 올릴 때도 `배포.bat` 만 다시 실행하면 됩니다.

## 방법 2 — 대시보드에 끌어다 놓기 (가장 쉬움, 자동 갱신 없음)

Cloudflare 대시보드 → **Workers & Pages → 만들기 → Pages → 에셋 업로드(Upload assets)** → 프로젝트 이름 입력 → 이 폴더(또는 zip)를 끌어다 놓기 → 배포.

> ⚠ 끌어다 놓기 방식은 `functions` 폴더(자동 갱신)를 실행하지 않습니다. 사이트는 정상으로 나오고 지난 경기도 자동으로 빠지지만,
> 새 일정·점수·우천취소는 `schedule.json` 을 새로 만들어 다시 올려야 반영됩니다. 자동 갱신이 필요하면 방법 1이나 3을 쓰세요.

## 방법 3 — GitHub 연결 (저장소에 올리면 자동 배포)

대시보드 → Workers & Pages → 만들기 → Pages → **Git 연결** → 저장소 `dol2314/blog` 선택 →
- 프로덕션 브랜치: 이 파일이 있는 브랜치
- 프레임워크: 없음, 빌드 명령: 비움
- 루트 디렉터리(고급): `site/kbo2026/cloudflare`

## 올린 뒤 확인

- `https://(주소)/api/schedule` 을 열어 일정 JSON 이 보이면 자동 갱신이 동작하는 것입니다.
  (응답 헤더 `X-Schedule-Source: kbo` = KBO 에서 새로 받음, `bundled` = KBO 연결 실패로 기본 일정 사용)
- 첫 화면 → 날짜 아래 빨간 버튼 → 그날 안내가 나오면 끝

## 동작 방식

- 지난 경기: 방문자 화면에서 한국 시간 기준 경기 시작 4시간 뒤 자동으로 빠짐 (1분마다 다시 계산)
- 새 일정: `/api/schedule` 이 이번 달·다음 달 일정을 KBO 에서 받아 30분 동안 보관 (요청 16번, 무료 요금제 한도 안)
- KBO 연결이 안 되면 `schedule.json` 으로 자동 대체 — 화면이 비지 않음
- 다른 달 일정은 `schedule.json` 기준. 시즌 전체를 새로 받으려면 저장소의 `site/kbo2026/update_schedule.py` 로 `schedule.json` 을 다시 만들어 함께 올리세요
- 모든 버튼은 사이트 안 페이지로만 연결 (방송사 사이트로 바로 보내지 않음)

## 도메인 연결 (선택)

Pages 프로젝트 → **사용자 지정 도메인** → 도메인 입력 → 안내대로 DNS 추가.
