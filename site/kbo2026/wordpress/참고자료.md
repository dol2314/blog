# 참고자료 — 2026 프로야구 일정 중계

## 1. 글쓰기 구조 (참고 글: news.brightsitefeed.com/저장소/5018)

모든 안내 글은 같은 틀을 씁니다. 새 글(예: 「한국시리즈 중계 채널」)을 쓸 때도 이 순서를 따르세요.

1. **제목(H1)**: `2026 프로야구 ○○ 중계 … 총정리 / 방법!` — 연도 + 주제 + 혜택(무료·저렴하게 등)
2. **도입 3문단** (각 1~2문장)
   - 질문으로 시작: 「○○, 어디서 하는지 찾고 계신가요?」
   - 궁금증 유발: 「그냥 ○○하면 손해일 수 있습니다」
   - 예고: 「오늘은 ○○부터 ○○까지 알려드리도록 하겠습니다.」
3. **소제목(H2)** 3~4개 — 회색 배경 박스 (`kbo26-h2` 클래스)
4. 소제목 아래: **짧은 문단 2개 → 「▼ ○○」 안내 줄 → 표 또는 빨간 전폭 버튼**
5. 항목 나열은 **「✅ 항목」** 굵은 줄 (`kbo26-check`)
6. 버튼 문구는 「○○ 확인하기 >>」 처럼 행동 + `>>`

**참고 글과 다르게 한 점**: 버튼이 외부(방송사·OTT 사이트)가 아니라 **우리 사이트 안 페이지**로 갑니다. 계정 공유 서비스 같은 내용은 넣지 않았습니다.

### 워드프레스 블록에서 직접 만들 때
- 회색 소제목: 제목 블록 → 고급 → 추가 CSS 클래스 `kbo26-h2`
- ▼ 안내 줄: 문단 블록 + 클래스 `kbo26-pointer`
- ✅ 줄: 문단 블록 + 클래스 `kbo26-check`
- 빨간 버튼: 버튼 블록 → 너비 100% → 클래스 `kbo26-btn` (색은 플러그인이 #fd0000 으로 칠함)

## 2. 숏코드

| 숏코드 | 보여주는 것 |
|---|---|
| `[kbo_next]` | 다음 경기 카드 + 카운트다운 + 중계 채널 + 바로가기 버튼 |
| `[kbo_schedule days="30"]` | 남은 경기 날짜별 목록 (지난 경기 자동 제외). `demo="1"` 을 붙이면 기준 시각 바꿔 보기 버튼 |
| `[kbo_day]` | 주소의 `?d=2026-11-01` 날짜 안내 글 전체 (없으면 다음 경기일) |
| `[kbo_channels]` | 중계 채널 카드 모음 |
| `[kbo_channel_codes]` | 일정표 표기 → 채널 표 |

- 10/31 기준 남은 경기: 11/1(일) 14:00 플레이오프 5차전 KIA vs 삼성 @대구 (KBS 2TV, 시리즈 2승 2패), 11/12~14 도쿄돔 국제대회 6경기(중계 채널 발표 전). 한국시리즈 일정은 KBO 에 올라오는 대로 자동 반영.

- 「티빙이 2024~2026 KBO 유무선 중계권 보유」 문장 — 공식 발표로 한 번 확인
- 티빙 이용권 가격은 일부러 숫자를 넣지 않았습니다(자주 바뀜). 넣고 싶으면 앱에서 확인한 날짜와 함께 적기
