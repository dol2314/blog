# 2026 프로야구 일정 중계 — 워드프레스 적용 가이드

다른 컴퓨터에서 **브라우저만 있으면** 됩니다. 파이썬 등 설치할 것은 없습니다.
일정은 플러그인이 워드프레스 서버에서 KBO 공식 일정을 **30분마다 자동으로** 받아 옵니다.

## 준비물 (이 폴더)

| 파일 | 용도 |
|---|---|
| `kbo2026-schedule.zip` | 워드프레스 플러그인 (업로드용) |
| `pages/1-남은일정_kbo-schedule.html` | ① 남은 일정(랜딩) 페이지 내용 |
| `pages/2-날짜별안내_kbo-day.html` | ② 날짜별 중계 안내 페이지 내용 |
| `pages/3-TV중계채널_kbo-tv-channel.html` | ③ TV 중계 채널 안내 페이지 내용 |
| `pages/4-티빙시청법_kbo-tving.html` | ④ 모바일(티빙) 시청법 페이지 내용 |
| `참고자료.md` | 글쓰기 구조, 중계 표기표, 데이터 출처, 숏코드 정리 |

다른 컴퓨터에서는 GitHub 저장소 `dol2314/blog` → 브랜치 `claude/trusting-bohr-mrtahk` → `site/kbo2026/wordpress/` 에서 받으면 됩니다
(zip 파일은 눌러서 **Download raw file**, 페이지 내용은 **Raw** 를 눌러 전체 복사).

## 1단계 — 플러그인 설치 (3분)

1. 워드프레스 관리자 → **플러그인 → 새로 추가 → 플러그인 업로드**
2. `kbo2026-schedule.zip` 선택 → **지금 설치** → **플러그인 활성화**
3. 관리자 → **설정 → 프로야구 일정** 에서 **「저장하고 지금 일정 새로 받기」** 한 번 누르기 (1~2분)
   - 「저장된 경기 939개 · 마지막 갱신 …」처럼 나오면 성공
   - 실패해도 플러그인 안에 들어 있는 일정(10/31 기준)으로 바로 동작합니다. 호스팅에서 바깥 접속을 막는 경우이니 호스팅 고객센터에 `www.koreabaseball.com` 접속 허용을 문의하세요.

## 2단계 — 페이지 4개 만들기 (페이지마다 2분)

관리자 → **페이지 → 새 페이지** 를 4번 합니다. 각 페이지마다:

1. 오른쪽 위 **⋮ (옵션) → 코드 편집기** (단축키 `Ctrl+Shift+Alt+M`)
2. 해당 `pages/*.html` 내용을 **전부 복사해서 붙여넣기**
3. 다시 **⋮ → 비주얼 편집기** 로 돌아오면 블록이 보입니다
4. 제목·주소(슬러그) 입력 후 **공개**

| 페이지 | 제목 (예시) | 주소(슬러그) — 꼭 이대로 |
|---|---|---|
| ① | 2026 프로야구 일정 중계 | `kbo-schedule` |
| ② | 프로야구 날짜별 중계 안내 | `kbo-day` |
| ③ | 2026 프로야구 TV 중계 채널 총정리 | `kbo-tv-channel` |
| ④ | 2026 프로야구 티빙 중계 보는 법, 무료·저렴하게 시청하는 방법까지 | `kbo-tving` |

> 슬러그는 오른쪽 사이드바 **페이지 → 링크(URL)** 에서 바꿉니다.
> 다른 주소를 쓰고 싶으면 **설정 → 프로야구 일정** 에서 주소를 같이 바꾸고, 페이지 안 빨간 버튼 링크도 고치세요.

## 3단계 — 마무리

- **첫 화면으로 쓰려면:** 설정 → 읽기 → 홈페이지 표시: 정적인 페이지 → ① 선택. 그 뒤 **설정 → 프로야구 일정** 의 「남은 일정 페이지」를 `/` 로 바꿔 저장.
- **메뉴:** 외모 → 메뉴(또는 사이트 편집기)에 ①③④ 추가. ②는 날짜 버튼으로 들어가는 페이지라 메뉴에 넣지 않아도 됩니다.
- **캐시 플러그인**(WP Rocket, LiteSpeed 등)을 쓰면 그대로 두셔도 됩니다. 일정은 페이지가 열린 뒤 따로 불러오기 때문에 캐시 때문에 옛 일정이 보이지 않습니다.
- **확인:** ① 페이지에서 날짜 아래 빨간 버튼 → ② 페이지가 `?d=2026-11-01` 처럼 열리고 그날 안내가 나오면 끝.

## 동작 방식 (알아두면 좋은 것)

- 지난 경기: 방문자 화면에서 한국 시간 기준 **경기 시작 4시간 뒤** 자동으로 빠집니다(취소 경기는 시작 시각). 1분마다 다시 계산.
- 새 일정·점수·우천취소: 플러그인이 **30분마다 이번 달·다음 달** 일정을 다시 받습니다. 워드프레스 예약 작업(WP-Cron)은 방문자가 있을 때 돌기 때문에, 방문이 드문 사이트는 「지금 일정 새로 받기」를 가끔 눌러 주세요.
- 링크: 모든 버튼·채널 칩은 사이트 안 페이지로만 연결됩니다(방송사 사이트로 바로 보내지 않음).
- 2027 시즌: **설정 → 프로야구 일정** 에서 시즌을 `2027` 로 바꾸고 「지금 일정 새로 받기」.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 「일정을 불러오지 못했습니다」 | 보안 플러그인이 REST API(`/wp-json/`)를 막는지 확인 → `kbo2026/v1` 경로 허용 |
| 버튼 눌러도 페이지 없음(404) | 페이지 슬러그 확인, 또는 설정 → 고유주소 → 그냥 「변경사항 저장」 한 번 |
| 붙여넣었더니 「예상치 못한 콘텐츠」 블록 | 그 블록에서 **블록 복구** 누르기 (내용은 그대로) |
| 다음 자동 갱신 「예약 없음」 | 플러그인을 비활성화 → 다시 활성화 |
